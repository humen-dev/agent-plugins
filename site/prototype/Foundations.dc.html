Foundations

Tokens are CSS custom properties defined once in catalog.css; components read only tokens. Dark is the default on first visit, light is the toggle. Ratios are WCAG 2.x contrast, computed for each pair; text needs ≥ 4.5:1, UI boundaries (inputs, chips, cards, focus ring) ≥ 3:1.

Type

System fonts only — nothing to download, nothing from another origin. Sans: ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif. Mono (commands, paths, invokeAs): ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace. Sizes are rem so browser zoom and user font size apply.

Spacing, radius, targets

4-px base. Touch targets ≥ 44 px (chips 40 px tall with 8 px gaps). Labels get room for +30 % length: buttons and chips size to content and wrap, never fixed widths.

Breakpoints & motion

  • Mobile 320–767 px · desktop ≥ 768 px. Content max-width 1200 px, gutters 16 / 24 px. No horizontal page scroll; only command boxes and Markdown tables scroll inside themselves.
  • prefers-reduced-motion: all transitions and the skeleton pulse are off. State never depends on motion.
  • Theme: data-theme on the root, default dark regardless of OS; the choice is stored in localStorage (guarded with try/catch).
